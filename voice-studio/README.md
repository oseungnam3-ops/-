# AI 음성 스튜디오

대본을 입력하면 AI 목소리로 읽어 주고 mp3로 저장해 주는 앱 (타입캐스트 스튜디오 스타일).

- **무료 음성**: Microsoft Edge 신경망 음성 (`edge-tts`, API 키 불필요) — 한국어 선히(여)/인준(남)/현수(남) 외 영어·일본어·중국어
- **문단별 목소리·감정**(기쁨/슬픔/화남/높은 톤/낮은 톤/속삭임), 속도(0.5~2x), 쉼 길이
- **다운로드**: 한 파일 mp3 합치기 / 문장별 zip
- 서버 없이 `static/index.html`만 열면 브라우저 내장 음성으로 미리듣기만 가능

## 실행
```
pip install -r requirements.txt
python server.py        # http://localhost:8000
```
폰에서 쓰려면 같은 Wi‑Fi에서 `http://<PC IP>:8000` 으로 접속.

> 감정은 무료 음성에 감정 모델이 없어 속도·음높이·볼륨 조합으로 근사합니다.
> edge-tts는 비공식 무료 엔드포인트라 상업적 대량 사용에는 Azure TTS 정식 계약을 권장합니다.

## 모션 그래픽 영상 (🎬 모션 영상 버튼)
대본의 문단 = 장면 하나. `skills/motion-studio` 엔진(카메라 · 등장 · 전환 · 효과음)으로 mp4를 자동으로 굽고,
원하면 무료 AI 목소리 나레이션을 입힙니다. 분위기(팝/차분/청량/강렬) · 비율(9:16 · 16:9 · 1:1) · 화질 선택.
- 서버에 `ffmpeg`가 필요합니다 (Docker 이미지에는 포함).
- 배경음은 사운드폰트(GeneralUser-GS.sf2)가 있을 때만 켤 수 있어 기본은 효과음 + 나레이션입니다.
- 자동 장면 코드: `motion/scenes_auto.py`, 대본 → 아트보드 변환: `motion/gen.py`
