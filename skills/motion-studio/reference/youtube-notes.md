# 영상 메모 — «모션그래픽, 메뉴판에서 고르면 끝 | Claude 스킬 motion-studio» (미드저니 코리아 조남경, 2026-10-14)
(사용자가 전해 준 요약 · 영상 원문은 확인하지 못했다)
- 흐름: 고르고(메뉴판에서 효과 선택) → 주문하고(내용 붙여넣기) → 받으면 끝
- 고치는 법 3가지: 캔버스 글자 직접 수정 · 포스트잇 메모 · 코멘트로 콕 집어 지시 → «수정 끝». 고친 곳만 바뀌고 나머지는 유지
- 토큰: 미리 만든 파이썬 부품을 재활용해 수정해도 토큰이 거의 안 든다 (예: 손끝 한글 타자 — 자모 조합 · 지움 · 머뭇거림)
- 이 저장소 적용: 앱의 «글자 등장 효과(메뉴판)» = 자동 · 줄 올라오기 · 타자 · 팝 · 손글씨(core/write.py 자모 획 순서 쓰기)
