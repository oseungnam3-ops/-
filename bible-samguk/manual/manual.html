1게임 소개

「성경 삼국지」는 코에이의 「삼국지」처럼 성을 다스리고, 장수를 거느리고, 전쟁으로 땅을 넓혀 가는 역사 전략 시뮬레이션입니다. 무대는 성경의 역사입니다. 아브라함의 장막에서 시작해 여호수아의 정복, 사사 시대, 사울과 다윗의 왕국, 분열 왕국까지 여섯 시대를 골라 플레이합니다.

이 게임의 목표

땅을 많이 차지하는 것만이 목표가 아닙니다. 인물들과 대화하며 사명(미션)을 이루고, 백성을 돌보고 신앙을 지킬 때 「하나님 나라」 점수가 자랍니다. 점수는 0부터 100까지이고, 여섯 단계(광야의 장막 → 하나님 나라)로 올라갑니다.

각 시나리오에는 승리 목표(예: 약속의 땅 12성 차지)가 있지만, 목표를 이룬 뒤에도 계속 다스릴 수 있습니다.

📖 말씀
처형하거나 우상을 섬기는 선택은 나라 점수를 깎고, 포로를 너그럽게 풀어 주거나 구휼을 베풀면 점수가 오릅니다. 성경 사건마다 “순종”의 선택이 결국 나라를 세웁니다.

2시작하기

2-1. 게임 접속하기

  1. 휴대폰이나 PC의 인터넷 브라우저(크롬·사파리·엣지)를 엽니다.
  2. 주소창에 https://oseungnam3-ops.github.io/-/bible-samguk/ 를 입력합니다.
  3. 휴대폰에서는 공유 메뉴 → “홈 화면에 추가”를 누르면 앱처럼 아이콘으로 실행할 수 있습니다.
  4. 화면을 한 번 누르면 배경음악이 시작됩니다(브라우저 정책상 첫 터치 뒤에 소리가 납니다).

2-2. 시나리오와 세력 고르기

  1. 타이틀 화면을 아래로 내리면 여섯 시대의 시나리오 카드가 나옵니다.
  2. 카드 아래의 세력 버튼을 누릅니다. 금색 테두리에 “스토리”가 붙은 세력은 대화로 진행되는 사명 이야기가 있는 주인공 세력입니다. 처음이라면 스토리 세력을 고르세요.
  3. 세력 설명 창에서 「내 주인공으로 시작」 또는 「역사 인물로 시작」을 고릅니다.

2-3. 내 주인공 만들기

「내 주인공으로 시작」을 고르면 내가 직접 성경 이야기의 주인공이 됩니다.

2-4. 저장과 이어하기

  • 자동 저장 — 명령·전투·턴이 끝날 때마다 이 기기의 브라우저에 저장됩니다. 다음에 접속하면 타이틀의 「이어하기」로 계속합니다.

  • 다른 기기로 옮기기 — 같은 창의 「저장 코드 복사」로 긴 코드를 복사해 두었다가, 다른 기기에서 「저장 코드로 불러오기」에 붙여 넣습니다.

전체 지도 읽는 법

  • 세력 깃발 방패 — 성을 가진 세력의 색과 첫 글자. 👑 왕관은 도읍.
  • 성 이름표 — 이름과 (세력 이름). 내 성은 ★와 금색 테두리, 금색 점선 고리.
  • 숫자 상자 — 그 성의 병력.
  • 영토 색 — 성 주변이 세력 색으로 칠해져 누가 어디를 다스리는지 보입니다.
  • 「사명 !」 표시 — 지금 사명의 목표 성.
  • 조작 — 끌어서 이동, 두 손가락(또는 마우스 휠)으로 확대. 미니맵을 누르면 전체 지도로.
  • 성 누르기 — 내 성이면 영지로 들어가고, 다른 세력의 성이면 정벌 창이 열립니다.

4내정 — 나라 다스리기

4-1. 턴과 계절

한 턴은 한 계절(봄 → 여름 → 가을 → 겨울)입니다. 장수 한 명은 한 계절에 명령 하나를 받습니다. 모든 장수에게 명령을 내렸으면 턴 종료를 누릅니다. 계절이 바뀔 때 금·목재·석재가 들어오고, 가을에는 식량을 수확합니다. 병사들은 계절마다 식량을 먹습니다.

4-2. 건물을 눌러 명령하기

  1. 영지에서 건물 아이콘을 누릅니다.
  2. 건물 창에서 명령 버튼을 누릅니다.
  3. 맡길 장수를 고릅니다. 명령에 맞는 능력치 순으로 정렬되어 나옵니다.
  4. 결과가 건물 위에 떠오르고(예: “농업 +10”) 장수가 “명을 받들겠습니다!”라고 답합니다.

4-3. 건물 레벨업

  1. 건물을 누르면 레벨(Lv.), 지금 효과, 다음 레벨 효과, 업그레이드 비용이 보입니다.
  2. 「업그레이드 → Lv.N」을 누르면 공사가 시작됩니다. 건물 위에 “🔨 2계절”처럼 남은 기간이 표시됩니다.
  3. 공사는 성마다 한 번에 하나. Lv.1~3은 1계절, 4~6은 2계절, 7 이상은 3계절.
  4. 왕궁 레벨이 다른 건물의 상한입니다. 먼저 왕궁을 올리세요.

6사명(미션) 수행하기

사명은 시나리오의 이야기를 따라가는 장(章)별 미션입니다. 장마다 인물들의 대화 → 목표 → 보상 → 마무리 대화 순서로 진행되고, 이루면 다음 장이 열립니다.

사명을 수행하는 순서

  1. 화면 아래 사명 바에 지금 장의 제목과 목표, 진행도(예: 3/6)가 보입니다.
  2. 사명 바나 왼쪽 「임무」를 누르면 사명 화면이 열립니다 — 목표·보상·지나온 장 목록.
  3. 지도에 「사명 !」 표시가 있으면 그 성이 목표입니다.
  4. 목표를 이루면(턴 종료 때 또는 명령 직후) “사명 완수” 대화와 보상이 나오고 다음 장이 시작됩니다.
  5. 지난 장의 대화는 사명 화면의 「대화 보기」로 다시 볼 수 있습니다.
