# 목양온 (MokyangOn) - 파주목양교회 통합 교회 플랫폼

본 프로젝트는 파주목양교회 성도들을 위한 소모임 관리 및 온라인 양육 플랫폼인 '목양온'의 1차 MVP 웹 애플리케이션입니다.

## 폴더 구조
- `index.html`: 단일 진입점 (SPA)
- `css/`: 디자인 스타일시트
  - `styles.css`: 기본 테마 및 레이아웃
  - `mobile.css`: 모바일 앱 화면 디자인
  - `admin.css`: 관리자 대시보드 화면 디자인
- `js/`: 애플리케이션 로직
  - `db.js`: LocalStorage 기반 Mock 데이터베이스 및 초기 데이터
  - `auth.js`: 인증 및 권한 관리
  - `app.js`: 메인 앱 라이프사이클 및 화면 라우팅
  - `mobile.js`: 성도용 모바일 기능 구현
  - `admin.js`: 관리자용 웹 대시보드 기능 구현
